02 / THE LOOP

OPEN. SCREEN. TYPE. WAIT.

Four actions. No new mental model. The agent types into the pane, reads what a human would see, and waits for a pattern instead of sleeping.

01OPEN

Start a program in a new pane.

ssh, vim, htop, a REPL, an installer. A real TTY with a size you choose.

pilot open "ssh msi" --name remote
02SCREEN

Read the pane as text.

What a human would see, not raw ANSI: joined lines, trailing blanks trimmed, dead-pane banner removed.

pilot screen remote --lines 80
03TYPE

Send text and named keys.

Literal strings plus Escape, C-c, Up, Tab. Return by default.

pilot type remote keys="i" "port" "Escape"
04WAIT

Wait for a pattern, or quiet.

Redraws are asynchronous. Poll for a regex, or let the pane settle before reading it.

pilot wait remote "password:|[$#] $"

03 / THE BACKEND

THE NORMAL TERMINAL TOOL. IN A REAL TTY.

Set terminal.backend: pilot and every terminal call runs in a persistent shell. cd, exports and aliases survive across calls. A command that times out is left running, with its session name — not killed.

  • SURFACEa real TTY, 120×36
  • BACKENDtmux 3.8, private socket
  • TIMEOUT124, left attachable
  • TAKEOVERattach and type
TURN IT ON ↗
hermes — terminal.backend: pilot

05 / MANIFESTO

DRAG THE CORE. THE TEXT PARTING AROUND IT IS MEASURED, NOT WRAPPED.

A pipe is a one-way street. A terminal is a conversation: you type, it answers, you look, you type again. Pilot keeps that conversation alive — across calls, across tools, across machines — and hands you the keyboard whenever you want it.

06 / INSTALL

PUT IT ON YOUR machine.

01

Install from the catalog

02
